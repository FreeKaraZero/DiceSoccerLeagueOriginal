# Dice Soccer — remake

Modern, browser-based remake of *Dice Soccer* (Lambdamu Games, 2012). This repository only
contains the shipped iOS app bundle (`Payload/Dice Soccer.app`) — no original source code — so the
remake is written from scratch and driven by the data and art extracted from that bundle.

| Original | Remake |
| --- | --- |
| Objective-C + cocos2d-iphone 1.x, iOS SDK 5.1 (Xcode 4.3) | TypeScript + Phaser 3, built with Vite |
| Binary plists, `CgBI` (iOS-optimized) PNG sheets | JSON + standard PNG atlases, generated by `tools/extract_assets.py` |
| armv6/armv7 iPhone binary | any modern browser |

## Setup

```bash
npm install
npm run extract   # needs python3 + Pillow; writes public/ from ../Payload
npm run dev       # http://localhost:5173
```

`public/` is generated and git-ignored: the art and audio stay in the original bundle, and every
build re-derives them from it.

## Asset pipeline

`tools/extract_assets.py` reads the app bundle and writes:

- `public/data/*.json` — every game-data plist (players, abilities, season lineups, shop, tips…)
- `public/atlas/<Sheet>.{png,json}` — cocos2d sheets repacked upright and untrimmed, in the
  Phaser JSON-hash format. `tools/cgbi.py` decodes Apple's `CgBI` PNG variant (raw deflate,
  premultiplied BGRA) that Pillow cannot read.
- `public/images`, `public/audio`, `public/fonts` — loose art (retina variant preferred), sounds
  and the original Krungthep typeface

## What the game rules are, and where they come from

The rules were reconstructed from the in-game handbook pages, the tutorial strings and the data
files, all of which the pipeline extracts:

- A lineup is 7 players: `[GK, DEF, DEF, DEF, FWD, FWD, FWD]`; midfielders may fill either outfield
  line. Every player *is* a six-sided die whose faces are the `DiceSides` printed on his card.
- Each encounter the attacking trio rolls against the defending trio; the higher total takes
  possession and pushes the ball one zone. A tie moves nothing.
- Abilities fire on the roll of their owner's team (`BuffTrigger`: pair, triple, straight, all
  odd/even, odd/even total, or a specific face) and modify dice (double, subtract, re-roll, …).
- Reaching the opponent's goal zone triggers a shot: the central forward against the goalkeeper.
- Faces above 14 are the special sides of the original: `16..18` are `+1/+2/+3`, `24..26` grant
  re-rolls, `31..32` are wild sides that count for any combo but score nothing.

## Status

Playable single-match prototype: real players, real abilities, real season opponents, original art
and font. Not yet ported: seasons/tournaments progression, manage/bench/shop/achievement screens,
entourage abilities, ability targeting by the player (targets are currently chosen automatically),
multiplayer, audio.
